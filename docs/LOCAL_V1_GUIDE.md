# Shot2Agent Windows Local — 两分钟开始

当前候选版本：**1.0.0-rc.1**。原生 Explorer 粘贴的最终人工验收尚未完成；不是正式 v1.0.0。

1. 完整解压 Windows x64 ZIP，再双击 **Shot2Agent.exe**。保留 `runtime` 文件夹；不要直接在 ZIP 中运行。目标电脑无需安装 Node、Git、pnpm 或 Shot2Agent 命令行。Windows 需要 WebView2。
2. 第一次启动会显示添加 AI 助手。通过 GUI 发现或选择 Codex CLI / Claude Code，选择工作区和提示词；先安装并登录所选第三方 CLI。GLM 使用支持的 Claude Code CLI，填写网关地址、模型及 Token。保存 Token 不发送请求；“测试连接”可选且会消耗模型额度。Token 只进入 Windows 凭据管理器。
3. **设置**中独立开启剪贴板截图或截图文件夹。确认模式先预览再提交；自动模式需明确同意图片发送到所选模型。暂停会停止接收新图片。多图任务可添加、排序 2–5 张图片，一次提交为一个任务。
4. 文本剪贴板、文件剪贴板、保存 Markdown、Windows 通知分别配置。关闭全部输出仍保留历史。“复制文件”后到资源管理器 Ctrl+V 会粘贴真实 `.md`；Win+V 不能验证文件复制。Smart 检测到新剪贴板活动会停止自动覆盖；Always 需要覆盖同意。
5. 历史中可以查看、复制和删除结果。“重试投递”只处理已生成结果，不重新请求 AI。结果不确定的任务不会自动重新执行。

关闭窗口会隐藏到托盘；从托盘选择 **Quit Shot2Agent** 才会退出。设置页显示版本、数据目录和文件复制缓存占用。构建完整源码 SHA 在同目录 **BUILD.txt**。

## 缓存与升级

文件复制缓存上限为 1000 个文件 / 256 MiB。**设置 → 清理旧复制缓存** 会请求确认，只清理超过 10 分钟的旧缓存，保留当前剪贴板引用的文件和近期文件。清理不删除历史、截图或导出的 Markdown。剪贴板被占用或内容无法可靠读取时不清理；等占用结束或重启后再试。近期文件到期后可再次清理。清理失败可能已删除部分旧文件，刷新后显示实际占用。

升级前从托盘退出，复制设置页显示的**整个数据目录**到安全位置。把新版完整解压到另一个目录后启动，即可沿用原数据。不要在运行时仅复制 SQLite 文件。Token 不在文件备份中；迁移到另一台电脑后在 GUI 重新填写。回退时先退出并保留当前数据副本，再恢复整份旧备份和旧程序。备份含有私有截图和结果，请勿公开上传。

## 仅用于最终验收的离线 Fake 模式

双击 **Start acceptance.cmd**，打开隔离的 Fake 测试窗口，不使用真实 Token、截图或历史。该窗口会准备一张合成 PNG 的预览；点击提交，等待 Fake 完成。不会访问模型。

在历史点击“复制文件”，到空 Explorer 文件夹 Ctrl+V；再点一次复制文件，在第二个空文件夹粘贴；第三次复制后关闭应用窗口隐藏到托盘，再到第三个空文件夹粘贴。三次都应生成可打开的 `.md`，应用保持后台不抢焦点。记录尝试次数、Paste 是否可用、错误码及文件是否出现。该测试验证文件传输，不代表真实模型视觉识别。

## 已知限制

Remote/VPS/Relay 尚未纳入 Local 发布。第三方 Agent 安装、登录和在线模型费用由用户自行管理。Windows 通知可被系统设置隐藏；Smart 不保证所有 IME/同步软件兼容。文件复制目前提供 Markdown 结果。没有验证所有提供商及所有 Windows 环境。
