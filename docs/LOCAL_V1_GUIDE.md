# 快速开始

这份指南带你完成第一次截图处理。所有 Shot2Agent 配置都在窗口内完成。

## 1. 下载并打开

从 [Releases](https://github.com/blooddrunk/Shot2Agent/releases) 下载 **Shot2Agent-Windows-x64.zip**，完整解压，双击 **Shot2Agent.exe**。

必须让 EXE 和 `runtime` 文件夹保持同级。其余脚本不是日常启动的必需项。若提示缺少 WebView2，请安装 [微软 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 2. 添加一个 AI 助手

先按提供商说明安装好 Windows 本机助手程序。Codex、Claude Code 个人登录方式还需要完成该程序的登录；GLM 方式使用自己的 GLM Token。

1. 在 Shot2Agent 点击“添加 AI 助手”。
2. 选“Agent 类型”，在“本机安装”中选择程序。列表为空时，点击“浏览 CLI 程序…”选择实际安装文件。
3. 给助手取名，例如 `my-codex`。名称只用小写英文字母、数字和短横线，以字母开头。
4. 工作区和提示词可以先保留默认值。若选 GLM，填好端点、图片模型和 Token。
5. 点击“保存 Agent”。

“测试连接”是 GLM 的可选操作，会发送合成图片，可能收费；不用先点它才能使用。保存按钮不会发起模型请求。具体支持版本和每个字段的含义见[配置 AI 助手](USER_GUIDE.md#配置-ai-助手)。

## 3. 开启截图预览

到“设置”：

- 勾选“监听剪贴板中的新图片”。
- 提交方式选“确认后提交”。
- 剪贴板返回选“手动复制”。
- 点击“应用设置”。

右侧出现“尚未保存”时，说明改动还没有生效。首次开启或恢复监听时，应用会跳过剪贴板里已有的图片，所以请在应用设置后截一张新图。

## 4. 提交第一张截图

按 **Win + Shift + S**，框选需要处理的区域。回到首页看到预览后，点击“提交图片”。该操作会把图交给选中的模型，可能产生费用。

不想开启监听时，可以截完图后直接点击“处理剪贴板图片”；这个按钮会直接创建任务，不经过确认预览。

## 5. 取回结果

任务完成后，打开历史：

| 按钮 | 用法 |
| --- | --- |
| 复制文本 | 粘贴到记事本、编辑器或聊天输入框 |
| 复制文件 | 到资源管理器的目标文件夹按 Ctrl+V，得到 `.md` 文件 |
| 重试结果投递 | 使用已有结果重试复制、保存或通知；不会再请求 AI |

Markdown 就是带有标题、列表等简单排版标记的文本文件，可以用记事本或支持 Markdown 的编辑器打开。

窗口关闭后，应用会留在托盘继续工作。完全退出请在托盘菜单选择 **退出 Shot2Agent**。

遇到问题时，先看[常见问题](USER_GUIDE.md#常见问题)。想配置文件夹监听、多图、自动复制、快捷键或备份，继续看[完整使用手册](USER_GUIDE.md)。
