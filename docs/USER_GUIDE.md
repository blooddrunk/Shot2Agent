## 安装和启动

从 [Releases](https://github.com/blooddrunk/Shot2Agent/releases) 下载 Windows x64 ZIP，选择正式版。Source code 是开发源码，不是应用；`rc` 是候选版本。

完整解压到一个你有写入权限的目录，例如 `D:\Apps\Shot2Agent`，双击 **Shot2Agent.exe**。程序不是单文件版，必须保留同级 `runtime` 文件夹。不要在压缩包里直接运行，也不要只复制 EXE 到桌面；需要桌面入口时，为 EXE 创建快捷方式。

应用需要 Windows 11 x64 和 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。Shot2Agent 自带 Node，不需要为它另装 Node、pnpm 或 Git。第三方助手可能有自己的安装要求，以其官方文档为准。

关闭窗口会隐藏到托盘。点击托盘图标或菜单可以回到窗口；菜单 **退出 Shot2Agent** 完全退出。正式使用时打开 EXE 即可，不必运行附带的 `.cmd`。

## 托盘状态

不用打开窗口，也能通过图标轮廓和中文提示判断状态：圆点代表监听，双竖线代表暂停，感叹号代表待确认，三横线代表排队，三角形代表处理，横线代表未开启，叉号代表异常。悬停提示同时显示捕获和任务状态及队列数。异常优先于处理，处理优先于待确认。

暂停或关闭监听只影响新图片，已提交的任务继续处理。恢复监听只接收此后新增的图片。待确认时单击托盘或选择“查看待确认图片”回到首页；截图本身不会主动弹出窗口。右键菜单的暂停和恢复互斥；无结果、无失败通道或没有其他助手时，相应操作不可用。关闭窗口仍会继续工作；“退出 Shot2Agent”才完全退出。

历史中的“重试结果投递”只在有可重试的失败通道时出现，只重新复制、保存或通知，不重新请求 AI。剪贴板冲突和结果不确定的写入不盲目重试，可以检查结果后手动复制。

## 配置 AI 助手

“AI 助手”页面保存你使用哪一个程序、工作区和提示词。这里的 Agent 指处理截图的 AI 助手程序。

### 先准备本机程序

| 类型 | 外部准备 | 在应用中选择 |
| --- | --- | --- |
| Codex | 按 [Codex CLI 官方说明](https://developers.openai.com/codex/cli/)安装 Windows 本机程序，并完成登录 | Codex CLI |
| Claude Code 个人登录 | 按 [Claude Code 官方说明](https://code.claude.com/docs/en/setup)安装并完成个人账号登录 | Claude Code 个人登录 |
| GLM | 安装受支持的 Claude Code，准备 GLM 服务的 Token | GLM（通过 Claude Code） |

**本版 Claude Code 和 GLM 通道支持 `2.1.305`、`2.1.306`。** 其他版本可能被拒绝，不表示 Token 错误。Claude Code 的官方安装页有指定版本的安装说明。Codex 会检查所需参数与程序身份，也不保证任意版本可用。

选择的是这台 Windows 上的安装，不是 WSL 里的 Linux 程序。GLM 通道仍使用 Claude Code 作为本机执行程序，只填写 Token 而没有程序安装不能运行。不需要为 GLM 方式另外登录 Claude 个人账号。

### 添加和选择

1. 点击“添加 AI 助手”，选择类型。仅发现一种兼容安装时会预选该类型；发现多种或无法确定时，请明确选择 Codex / Claude Code / GLM。不会默认进入 GLM Token 表单，也不会改变已保存的默认助手。
2. 在“本机安装”选择检测到的程序。没有列出时，点击“浏览 CLI 程序…”，选择真实安装的 `.exe` 或应用能识别的 `codex.cmd` / `claude.cmd` 启动入口，不要选择自己拼接的脚本。
3. 填“Agent 名称”。例如 `my-codex`、`my-glm`；以小写字母开头，最多 64 个小写字母、数字或短横线。
4. 填完后点击“保存 Agent”。有多个助手时，点“设为默认”选择后续截图使用哪一个。

Windows 原生 Codex 安装器的默认位置 `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin` 会自动检测。该入口可能是目录链接；首次保存时应用会绑定它指向的真实版本文件。Codex 更新后，已有助手配置和任务仍保留原版本；需要使用新版时，请重新检测并编辑助手配置。若原版本已被移除，应用会拒绝执行并要求重新配置。

### 工作区和提示词

展开“高级配置 · 工作区与提示词”：

| 字段 | 含义和建议 |
| --- | --- |
| 工作区 | 助手运行时使用的本机目录。没有特别需要时，点击“使用 Shot2Agent 默认工作区”；也可选择自己有权限访问的普通文件夹 |
| 默认提示词 | 每次处理图片时交给助手的要求。可以填写“请提取图片中的文字，保留段落，以中文 Markdown 返回”，或“解释截图中的报错，并给出排查步骤” |

默认按只读方式执行。选择目录不是授予 AI 随意改文件的许可。不要选择网络共享、目录链接或无法访问的位置。

编辑配置只影响以后提交的任务。已排队和已有任务保留提交时的助手版本；换助手不会把旧任务交给另一个模型，也不会重新处理它。

### GLM 端点、模型与 Token

| 字段 | 填写方式 |
| --- | --- |
| GLM 端点 | 国内服务选 `https://open.bigmodel.cn/api/anthropic`；国际服务选 `https://api.z.ai/api/anthropic`。使用与你的账号、Token 对应的服务。本版只接受这两个地址 |
| 模型 | 填服务账号可用、且本版支持的图片模型名称，例如 `glm-5.3-flash` |
| GLM Token | 填该服务签发的 Token。保存后不回显，不写入普通配置文件 |

本版图片通道接受 `glm-5.3-flash`、`glm-4.6v`、`glm-4.6v-flash`、`glm-4.6v-flashx`。这只是应用允许使用的名称，不保证你的账号有额度、服务端当前可用，或已经在这台电脑上验证过识图效果。

点击“保存 Agent”只保存本地配置和 Windows 凭据。**不会自动测试，不会发起模型请求。** 你可以随后提交自己的截图；提交本身可能收费。

“测试连接”是可选操作。确认后会发一次合成图片请求，可能收费；不用先测试才能使用。测试通过仅说明这次端点、模型和凭据组合通过了该项测试。

### 更换 Token、移除助手与旧配置

在助手旁点击“更换 Token”或“编辑配置”。编辑时 Token 留空会沿用已保存凭据；填写新 Token 则保存新的凭据。不要通过修改 JSON 来更换 Token。

“移除 Agent”将它从日常选择列表中移除，可以恢复。当前默认助手需要先换成另一个，才能移除。已有任务引用的旧配置仍保留。

旧配置清理只删除不再被任务引用、也不再用于选择的版本。仍被其他版本共用的 Token 不会随单个版本删除。若要永久清理助手和 Token，先处理相关历史和其他引用，再到“AI 助手 → 高级清理”使用“永久删除未引用版本”或批量清理操作；不要手工删除数据目录里的零散文件。

## 截图与多图任务

### 处理一张图片

按 **Win + Shift + S** 截图。确认模式下，应用显示预览，点击“提交图片”才会交给助手；“丢弃”不会创建任务。也可以把预览加入多图草稿。

首页“处理剪贴板图片”是手动的一次性提交：直接处理当前剪贴板中的图片，不需要开启监听，也不经过预览确认。只复制图片文件的路径或资源管理器里的文件，不一定等于剪贴板中有图片内容。

应用不提供截图标注工具。可以先在其他软件中裁剪，再把图片放入剪贴板或截图文件夹。

### 处理相关的 2–5 张图

在首页“多图任务”点击“添加图片文件…”，或从当前剪贴板、待确认预览添加。按“上移”“下移”调整顺序，“移除”删除单张。

确认顺序后，点击“提交 N 张为一个任务”。助手会在一个任务里收到这些图片。编辑期间的新截图不会擅自加入草稿。“丢弃多图草稿”不创建历史，也不请求模型。

支持 PNG、JPEG、WebP 静态图片。单张提交数据上限 20 MiB，整组 60 MiB，最多 5 张；异常尺寸、损坏文件和动画图片会被拒绝。校验失败时不会只提交半组。

## 捕获设置

修改后点击“应用设置”。“尚未保存”表示页面是草稿，监听方式还没有变。

| 设置 | 行为 |
| --- | --- |
| 监听剪贴板中的新图片 | 读取之后出现的新图片，不处理普通文字 |
| 监听截图文件夹（仅此目录） | 接收该目录中新写入的图片，不搜索子文件夹；等待文件写入稳定后再读取 |
| 确认后提交 | 先显示预览，点击提交后才请求助手 |
| 自动提交 | 新图片直接交给当前助手；必须先同意截图自动发送，在线模型可能收费 |

文件夹和剪贴板可以独立开启，也可以同时开启或都关闭。文件夹不要与应用数据目录、结果保存目录相同，也不要相互包含，避免输出再次成为输入。

**首次开启、重启、恢复或应用配置后，会跳过已有图片。** 请在完成设置后截一张新图，或把新文件放入所选文件夹。不要把已完成的旧截图批量搬入监听目录，除非你确实希望再次处理。

同一次截图在文件夹和剪贴板中出现时会进行短时间去重；手动提交同一张图仍可以再次创建任务。若预览中已有剪贴板截图，新的剪贴板图片可能替换它，请以页面当前预览为准。

“暂停捕获”停止接收新图片，**不会停止已经排队或正在执行的任务**。恢复后不补处理暂停期间已有的图片。

## 结果去向

历史始终保留。下面的输出可独立选择：可以同时开启，也可以全部关闭。

### 剪贴板返回

| 选项 | 含义 |
| --- | --- |
| 关闭 | 不自动复制；需要时仍可在历史点复制按钮 |
| 手动复制 | 完成后由你在历史里点击复制 |
| Smart · 保护后来复制的内容 | 只有剪贴板在提交后没有被其他操作改变，才自动复制；发生变化就保留新内容 |
| Always · 总是覆盖 | 完成时覆盖剪贴板，需要单独勾选同意 |

“自动复制内容”选择一种：文本，或 Markdown 文件。文本用于粘贴到编辑器；文件用于在资源管理器按 Ctrl+V。剪贴板会被后续复制活动替换，自动复制不会永久占用它。

如果 Smart 跳过复制，到历史点“复制文本”或“复制文件”即可。反复重试投递不会绕过原来的保护，也不建议为此反复请求模型。

### 自动保存 Markdown

勾选“自动保存 Markdown”，通过“选择文件夹…”指定输出目录，再应用设置。文件名使用任务 ID，扩展名为 `.md`。已有不同内容的同名文件不会被覆盖。

Markdown 是可直接阅读和编辑的文本格式，记事本也可以打开。它与输入的截图不是同一个文件；文件复制目前提供的是 Markdown 结果，不是任意 AI 生成的附件。

### Windows 通知

勾选“完成时显示 Windows 通知”。Windows 的通知、专注或勿扰设置可能隐藏提示，历史里的结果仍可查看。

### 一个输出失败怎么办？

任务成功与输出状态分开。例如自动保存成功、剪贴板失败时，AI 的结果仍然存在。检查相应错误，再使用“重试结果投递”。这个按钮只使用已有结果，不重新运行 AI，也不会产生新的模型处理请求。它不会反复重做已经成功的输出。

设置中的“高级设置 → 投递失败重试”控制有限的额外尝试次数、初始等待和时间预算。通常保留默认值即可；增加重试不能解决 Smart 冲突、无权限或结果不确定的问题。

| 高级重试字段 | 默认值 | 可填范围 |
| --- | --- | --- |
| 额外尝试次数 | 0 | 0–10 |
| 初始等待（毫秒） | 100 | 10–1000 |
| 每通道时间预算（毫秒） | 3000 | 100–10000 |

这些值与捕获、结果设置一起点击“应用设置”保存。只有可确认的暂时性失败才自动重试；可能已经写入的剪贴板操作不会盲目再做一次。

## 历史记录

点击任务可以查看结果和处理信息。支持搜索、翻页、单条删除、多选删除和批量清理。

- 删除历史会清理该任务的应用私有截图和结果数据。
- 已经导出到其他目录的 Markdown 不会被历史清理删除。
- 已复制文件的缓存单独管理，删除历史不会立即让当前文件粘贴失效。
- 排队或运行中的任务不会因清理历史被删除。

“执行结果不确定”表示应用无法确认已启动的助手最终做了什么。应用不会自动重跑，也不会自动换助手。检查后可以按页面提供的明确确认操作清理这类记录。若仍要重新处理，请明确提交一个新任务，并考虑可能重复请求或重复操作。

## 外观与快捷键

浅色、深色主题可以在侧栏或“设置 → 外观”切换。主题只改变显示，不改变任务或输出配置。

“全局快捷键与操作”默认关闭。可使用 `Ctrl+Alt`、`Ctrl+Shift` 或 `Alt+Shift` 加一个字母或数字，例如 `Ctrl+Alt+S`。填好后点击“保存快捷键”；清空并保存可取消绑定。

尚未配置 AI 助手时也可以保存快捷键。若保存失败，按钮下方会说明是 Windows 注册失败、配置写入失败或格式问题，并显示错误代码；请保留该代码。程序路径检测失败本身不会阻止快捷键保存。

可绑定暂停/恢复、复制最新成功结果、重试最新失败投递、循环切换助手、提交当前剪贴板图片。不要和截图工具或其他软件抢用同一个组合键；注册失败时选择另一个组合。后台使用快捷键也会执行对应操作，提交图片的快捷键会创建真实任务。

## 文件复制缓存

“复制文件”需要一份保留在磁盘上的文件，才能稍后粘贴。设置页显示这个专用缓存的路径、文件数和空间占用，上限是 **1000 个文件 / 256 MiB**。

点“清理旧复制缓存”，确认后只删除超过 10 分钟的旧缓存。当前剪贴板仍引用的文件和近期文件会保留；导出的 Markdown、任务历史和截图不受影响。因保留规则没有立即释放空间时，等近期文件超过 10 分钟后再试。

剪贴板被占用或无法可靠读取时，不会强行清理。缓存中存在不认识的文件或链接，也会拒绝操作。清理中途失败可能已经删除了部分旧缓存，刷新后以实际占用为准。不要直接清空整个缓存目录。

## 升级、备份与回退

程序目录和数据目录不同。替换解压的程序文件不会自动删除任务历史。

1. 在设置中找到“版本与备份”，记下显示的数据目录。
2. 等待正在处理的任务完成，从托盘退出应用。
3. 将**整个数据目录**复制到安全位置作为备份。不要在运行时只复制 `*.sqlite` 文件。
4. 将新版完整解压到另一个目录，双击新版 EXE。正常入口会继续使用原有数据。

正常入口的数据通常在 `%LOCALAPPDATA%\Shot2Agent-Codex`，以设置页实际显示为准。旧兼容入口使用另一个数据目录，启动后看到的历史可能不同。

Token 保存在 Windows 凭据管理器，**不包含在目录备份里**。在同一 Windows 用户下升级会继续引用已保存凭据；换电脑或换 Windows 用户需要在 GUI 重新输入 Token。数据备份中包含截图和结果，请按私人文件保管。

需要回退时，先退出应用，另外保留一份当前数据，再恢复完整的旧数据备份并使用对应旧程序。不要在不同版本之间随意拼接数据库、配置和截图文件。正式升级前仍建议备份，即使本版已用旧版本合成数据完成升级回归。

## 安装包文件说明

| 文件或目录 | 日常运行是否必需 | 用途 |
| --- | --- | --- |
| `Shot2Agent.exe` | 是 | 应用窗口、托盘和本机进程管理 |
| `runtime/` 整个目录 | 是 | 随包提供的 Node、应用代码、图片依赖、Windows 辅助脚本和资源，必须与 EXE 同级 |
| `Start Codex.cmd` | 否 | 兼容启动入口，与正常 EXE 使用相同的 Local 数据目录 |
| `Start legacy Local.cmd` | 否 | 打开早期 Local 数据目录；只有查找旧历史时才需要 |
| `Start acceptance.cmd` | 否 | 开发验收用离线 Fake 环境，每次使用独立临时数据；不代表真实模型识图 |
| `Windows instructions.md`、`LOCAL_V1_GUIDE.md`、`USER_GUIDE.md` | 否 | 离线快速开始和本手册 |
| `BUILD.txt`、`MANIFEST.json` | 否，建议保留 | 构建版本、完整源码提交和资源校验信息，排查版本时有用 |
| `Validation and acceptance.md`、可能存在的 `SMOKE.txt` | 否 | 开发和打包验证说明/结果 |
| `THIRD_PARTY_NOTICES.md` | 不参与执行，分发时保留 | 图标库等第三方许可说明 |

`runtime/node.exe`、`runtime/dist/` 和 `runtime/node_modules/` 都是运行内容，不要按扩展名自行删减。`dist` 里的 `.ps1` 是应用的固定 Windows 辅助程序，也要保留。用户电脑不需要再安装一套 Node。

Releases 页面另附的 `SHA256SUMS.txt` 用于核对 ZIP 是否完整，不是运行依赖。不要把程序目录当作任务数据备份。

## 常见问题

### 双击后打不开，或提示缺少文件

确认已经完整解压，EXE 旁边有 `runtime`。出现 WebView2 提示时安装微软运行库。不要只移动 EXE；为原位置的 EXE 创建快捷方式。若仍报错，保留提示中的错误代码和 `BUILD.txt` 版本，不要公开上传自己的数据目录。

### 列表里找不到助手

先确认已安装 Windows 本机程序。用“浏览 CLI 程序…”选择实际入口。出现“不兼容”“版本或文件已变化”时，说明检测到的程序不满足本版要求，或原安装已更新；重新检测并保存受支持的配置。不要把 Linux/WSL 路径填进 Windows 程序路径。

### 截完图没有预览

确认“监听剪贴板中的新图片”已勾选、点击过“应用设置”，并且没有暂停。开启后重新截一张；启动前已有的图片会被跳过。也可以在首页点“处理剪贴板图片”进行一次性提交。

文件夹方式请核对截图工具实际保存的位置、只监听当前目录这一点，以及图片是否已经写入完成。保存到子文件夹不会被接收。

### GLM 提示凭据、模型或连接错误

在“AI 助手”点“更换 Token”，确认端点与 Token 所属服务一致。核对模型名称、图片支持、账号额度和网络。Claude Code 版本不支持时，先处理本机程序版本，反复换 Token 没有帮助。需要做付费连接测试时再主动点击“测试连接”。

### 复制后粘贴不了文件

在历史点“复制文件”，随后在资源管理器的目标文件夹按 Ctrl+V。不要用 Win+V 的展示结果判断文件剪贴板。期间复制了其他内容会替换剪贴板，回到历史再点一次复制即可；先不要重新请求 AI。

出现 `CLIPBOARD_BUSY` 表示被其他程序占用，稍后手动复制。显示“随后被替换”表示写入后发生了新的剪贴板活动。缓存满时到设置清理旧复制缓存；不要直接删除正在被剪贴板引用的文件。

### AI 成功了，自动复制或保存却失败

结果没有丢。先在历史查看结果，再按具体输出错误处理。可以手动复制，或使用“重试结果投递”；它不会再次运行模型。

### 为什么关闭窗口后还在处理？

关闭窗口是隐藏到托盘。暂停只停止捕获新图片。要退出应用，请使用托盘的 **退出 Shot2Agent**；尽量等正在处理的任务结束，避免退出后出现结果不确定状态。

### 怎样反馈问题？

记录应用版本、`BUILD.txt` 中的 Commit、在哪个页面点击了什么、期望和实际结果，以及可见错误码。需要截图时使用不含私人信息的示例。不要发送 Token、真实截图、完整数据目录或私人结果文件。
