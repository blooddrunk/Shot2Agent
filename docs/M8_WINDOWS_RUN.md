# M8-L 0.8.0 Windows 使用

解压完整 Windows x64 ZIP，双击 **Shot2Agent.exe**。WebView2 和所选 Agent CLI 的安装/登录是外部前提；目标机无需 Node、pnpm、Git 或 Shot2Agent 命令行。关闭窗口隐藏到托盘；托盘 Quit 退出。Agent、Token 和历史沿用原数据目录。

## 输入

在“设置 → 捕获”独立开启“监听剪贴板中的新图片”和“监听截图文件夹”。目录通过“选择截图文件夹…”选择；只处理该目录的 PNG/JPEG/WebP，不递归。两者都关闭时仍可手动处理、查看历史。

首次开启、重启、恢复或应用配置时跳过已有图片。文件属性稳定至少 1.2 秒后读取，再等待内容稳定至少 1.2 秒，避免读取写入中的截图；每轮扫描最多 1024 项、读取 4 个候选，轮询约 600 毫秒。目录过大、无权限、无效文件会显示诊断。符号链接不作为输入。应用数据和 Markdown 输出目录不能与截图目录相互包含。

确认模式显示待确认预览；文件输入可排队至 21 个内存预览。提交、丢弃或加入多图任务后进入下一个。剪贴板的新预览替换尚未确认的剪贴板预览。自动模式要求原有云图片同意。暂停仅停止捕获，已排队任务继续处理。

相同图片在 5 秒窗口内自动去重，覆盖文件与剪贴板来源；确认预览合并相同内容。手动“处理剪贴板图片”“提交图片”和多图提交允许明确重复。

## 多图

首页“多图任务 · 2–5 张”可从文件选择器、当前剪贴板、待确认预览添加图片。缩略图按提交顺序排列；“上移/下移/移除”支持键盘。丢弃草稿不创建历史。

“提交 N 张为一个任务”将全部图片和提交时选择的 Agent 版本固定为一个任务。监听不会修改草稿。最多 5 张、总输入不超过 60 MiB，单张发给 Core 不超过 20 MiB；沿用既有像素/尺寸和无损优化限制。全部校验通过才创建任务；失败保留草稿，不发布半个任务。

## 输出

“剪贴板返回”可选关闭、手动、Smart、Always；自动复制内容独立选择文本或 Markdown 文件。Always 仍需明确覆盖同意；Smart 保留原序列保护，不因投递重试重设。历史提供分别复制文本/文件的按钮，手动复制表示明确覆盖。

“复制文件”写入原生 CF_HDROP 文件列表，可在资源管理器粘贴 .md 文件；不会复制输入截图或不受控附件。文件位于当前应用数据目录 `file-clipboard`，使用原子无覆盖发布和内容验证。即使删除历史或退出应用也保留这些已向剪贴板公布的文件，最多 1000 个/256 MiB，达到配额会报告失败，不擅自删除仍可粘贴的文件。用户自行清理会使旧文件列表失效；完整缓存管理属于 M9。

Markdown 自动保存、剪贴板、Windows 完成通知可同时或独立启用，也可全部关闭仅留历史。每个渠道有独立持久结果；一个失败不会使 AI 任务失败。系统通知采用 Windows 原生托盘气泡 API，无需安装器或 Relay；Windows 的通知设置可能隐藏气泡。成功回执仅代表系统 API 接受，不能证明屏幕显示。升级不会给旧完成历史补发通知。

“重试结果投递”使用已有结果，**绝不重跑 AI**。保持现有有界重试、Smart 原始基线和不确定写入不自动重试规则。未新增 Agent rerun。

## GLM

保存 Token 只写入 Windows 凭据管理器，不请求模型。支持的图片模型可直接处理用户提交的截图，不要求先付费合成测试。“测试连接”仍为可选，点击确认后才发送一次合成图片，可能收费。旧测试状态仅用于诊断，既有任务绑定及凭据引用保持不变。模型不支持图片、Token/网络失败仍会给出错误，不自动重跑。

## 最短原生验收（仅自动化未覆盖部分）

前提：从 PR/主线 Windows desktop package 下载完整 ZIP 并解压；使用单独的 **Start acceptance.cmd** 隔离 Fake 环境（不触碰正式历史/Token），准备几个小型合成 PNG 和空截图/粘贴目录。Fake 默认约等待 8 秒；不用真实 GLM。

1. 设置剪贴板返回为手动。打开目录监听并通过原生选择器选合成截图目录。开启前已有图片应不出现；之后复制一个新文件到目录，约 3 秒后只出现一个预览。提交后只有一个 Fake 任务。暂停期间新增图片、恢复后不应补发。证明原生目录交互与基线；不证明云模型。
2. 首页添加 2–5 张合成图片，调整顺序，提交一次。历史应出现一个多图任务。点击“复制文件”，在空资源管理器目录按 Ctrl+V，应出现可打开的真实 .md 文件而非路径文字。证明实际 Explorer 粘贴；不证明任意二进制附件。
3. 勾选 Windows 通知、再提交一个不同合成图片，等待气泡且当前窗口焦点不变。关闭全部输出再提交，结果应仅留历史；退出重开后仍在。系统禁止气泡时记录不可见，不把 API 成功写作可见通知验收。

完整开发证据见 [M8_VALIDATION.md](M8_VALIDATION.md)。
