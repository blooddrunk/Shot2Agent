# Local 桌面使用（M7-UX）

解压完整 Windows ZIP 后启动 **Shot2Agent.exe**。程序在本机保存任务，无需 Relay 或 VPS；云端 AI 仍可能需要联网及提供方账户。

- **首页**：当前助手、截图预览、处理剪贴板图片、暂停/恢复、最近三项结果。用 Win+Shift+S 截图，确认模式下点击“提交图片”。更多记录在“历史记录”。
- **AI 助手**：添加、编辑、设为默认、移除与恢复都在这里。Codex / Claude Code 需要先在本机安装并完成提供方登录，应用会自动检测程序。找不到时可浏览程序。工作区和提示词在编辑窗口“高级配置”中；默认工作区自动创建。
- **GLM**：选择 Claude Code + GLM，填端点、模型与 Token。点击“保存 Agent”仅存入 Windows 凭据管理器，不请求模型、不收费。之后可独立点击“测试连接”，先阅读费用提示；确认后发送一次程序自带合成图片。测试通过只代表这次连接图片测试通过。新 Token、端点或模型未测试前不能处理图片；不更改连接的编辑会保留已有图片资格。Token 永不回显，编辑时留空沿用。
- **历史记录**：查看详情、复制、搜索全部历史、分页浏览、删除、批量清理。每页最多 50 项，更早记录可以翻页查看。删除的是应用私有历史和附件，不会删除已导出的 Markdown。排队/运行任务会保留；结果不确定的任务只能在确认对应 Agent 停止后显式清理，绝不自动重跑。
- **外观**：设置中选择“深色”或“浅色”，立即生效并记住选择；左下角也能一键切换。左下角状态区分别显示捕获状态与任务处理/排队情况。
- **设置**：选择确认或自动捕获；自动提交需勾选同意。输出可手动复制、Smart 或 Always；Always 需单独同意覆盖。Markdown 保存独立启用，也可只保留历史。快捷键默认关闭，高级重试仅重试投递，不重新运行 AI。

编辑现有助手会生成新配置版本，既有任务继续绑定旧配置。编辑其他助手不会更换当前默认；使用“设为默认”明确切换。当前默认助手需先切换到另一个助手才能移除。已移除项可以恢复；每次编辑会保留原配置，供旧任务使用。“清理不再使用的旧配置”仅删除没有任务再需要的旧配置和凭据，当前配置和历史仍需使用的版本会保留。

关闭窗口会隐藏到托盘；完全退出请使用“退出应用”或托盘退出。
