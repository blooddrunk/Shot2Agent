## Goal A (first): configurable Windows global actions

Prefer existing Tauri 2/Rust tray and coordinator IPC rather than Node keyboard hooks. Investigate Tauri global-shortcut plugin and its precise Windows capabilities/permission model; alternatively use native RegisterHotKey if it better fits zero-WebView, background-safe state and avoids permissions drift. Register on startup and when settings change; unregister on exit and rollback on conflicts. Do **not** steal foreground focus, inject keystrokes, use admin elevation, install a low-level hook or reserve system defaults without operator opt-in. Default hotkey assignments may all be disabled; expose compact UI to edit, disable, reset, show effective registration status and conflicts. Persist only vetted combinations, enforce unique bindings and reject OS reserved/unavailable combinations. Make registry owned by the native process, not WebView (which can be hidden/throttled).

Expose an allowlisted native -> existing coordinator action layer, never arbitrary commands or executable paths:
- Pause/resume capture: toggle current state atomically on backend, not based on stale WebView snapshot. Do not cancel running tasks or submit old clipboard image on resume.
- Copy latest successful *result*: choose latest **durable completed** task by persisted completion ordering, not just newest submitted item and not latest failed/running task. Explicit copy is user-authorized; never activate or refocus the app. Clear no-result and Windows clipboard error status.
- Retry latest failed **result delivery**: reuse durable output with no Agent invocation. Resolve unambiguously which task is actionable; skip succeeded channels; respect disabled channels, sticky Smart sequence guards and pending/ambiguous policies, and explain no-op/no eligible channel instead of claiming success. Existing `retry-delivery` does not rerun models.
- Cycle approved Agents: exactly current worker-owned approved Profile list in deterministic order; selection affects only future submissions. Do not change queued/running jobs, auth profiles or executable pins. Refuse if only one available.
- Optional: submit current clipboard image explicitly, subject to existing dedupe and consent.

Actions must also be accessible via menu/UI and have testable backend command semantics. UI/toast feedback must be bounded and safe (no screenshot contents/secrets), visible when window is hidden where OS permits. Test: invalid/conflicting bindings; reconfigure/rollback; restart persistence; hidden-window no-focus; rapid repeats; backend unavailable; no-result; concurrent submission and switching; no new task on resume; delivery retry never calls Agent; release of registrations when app exits. Deterministic unit/process tests in CI; actual global shortcut delivery and focus require Windows interactive-session acceptance only if not automatable.

## Goal B (second, same bounded M6-L if practical): Claude-compatible gateway Profiles, prioritizing Zhipu GLM

Keep existing subscription Profile unchanged. Introduce distinct, **opt-in, immutable** `claude-compatible-endpoint` authentication/endpoint Profile, without weakening existing Claude isolation or opening generic launch IPC. UI/CLI must show the provider, endpoint host, model mapping, credential status and qualification without showing token. Support explicit HTTPS base URL allowlist/pinning, certificate/TLS verification, no arbitrary shell, bounded redirects and safe environment forwarding *only* for the approved profile. Specifically evaluate Zhipu domestic `https://open.bigmodel.cn/api/anthropic` and independently configured Z.AI international endpoint; do not assume credentials/regions are interchangeable. Model mapping and credential reference bind to immutable Profile/version/fingerprint when the task is queued. A change requires stopped Worker, backups and explicit approval; never silently change running/queued task destination or fall back to Codex/subscription Claude.

Store secret in Windows Credential Manager or audited OS-backed secure credential store, never settings.json, task DB, traces, test snapshots, Markdown, commits or console. If OS-backed secret storage unavailable, refuse the gateway profile rather than persist a plaintext key. Only the selected child process gets allowlisted `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` / correct key field, plus explicit model mapping; no broad inherited user environment. Redact API URLs if they can contain credentials/query strings; never leak tokens to child error/log/status. Define credential lifecycle (add/replace/delete) with confirmation and safe test doubles.

The current subscription preflight's `auth status` Pro/Max requirement must NOT apply to gateway credentials; instead verify the gateway policy and **no managed hooks/tools/MCP** under that credential. Existing Claude `--restricted --safe-mode --tools '' --disallowedTools 'mcp__*' --strict-mcp-config` confinement must remain fail-closed, including managed/remote policy and tool/command execution uncertainty. If a gateway CLI version or setting cannot be isolated, reject with a precise safe code rather than turn off safeguards. Distinguish HTTP auth failure, endpoint failure, unsupported model vision, CLI transport mismatch and real model success.

**Image capability gate:** text-only Claude Code or GLM response does not prove screenshot ingestion. Use mock gateway to assert ordered typed image blocks, byte integrity and exact endpoint/model routing without network/model cost; then provide an explicitly opted-in *single synthetic image* real-model test, with cost/token redaction, for a confirmed image-capable model/endpoint. Refuse known text-only endpoints and do not silently down-convert images or enable tools/MCP to simulate vision. If exact GLM compatibility and vision cannot be proved without real paid invocation, deliver gateway setup + reliable refusal/NOT VERIFIED evidence and keep live vision behind its gate; never claim it works.

No unattended auto-failover or Agent rerun, no Remote/VPS, no broad Profile editor, no cloud credential setup via task screenshots.
