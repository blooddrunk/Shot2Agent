# Shot2Agent Local v1.0.2 — Windows portable

本次是 Windows Local 桌面版的补丁更新，包含已合并的 [PR #24](https://github.com/blooddrunk/Shot2Agent/pull/24)，不引入 Remote / Relay。

## 修复与改进

- **原生 Codex 自动发现**：识别 Windows 安装器的默认目录 `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin`，支持目录 Junction，并将新选中的 CLI 绑定到真实版本路径。已有任务和 Agent 仍使用原来审核过的程序，版本或路径失效时要求重新配置。
- **快捷键保存更清晰**：在“保存快捷键”旁显示组合键冲突、格式错误或存储失败的原因及错误代码。注册失败时保留原设置和编辑草稿，避免把问题误报为 CLI 或网络故障。
- **首次配置更顺畅**：尚未添加 AI 助手、CLI 检测无有效结果时，也能独立保存全局快捷键。

## 下载与升级

下载本 Release 的 **Shot2Agent-Windows-x64.zip**，完整解压后运行 **Shot2Agent.exe**。必须保留同级的整个 `runtime` 文件夹；普通使用不需要执行 `.cmd`。

升级前从托盘 **退出 Shot2Agent**，备份设置页所示的完整本地数据目录，再将新版 ZIP 解压到新目录。Token 仍保存在 Windows 凭据管理器中；备份中可能包含私有截图和结果，请勿公开上传。
