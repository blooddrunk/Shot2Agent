# Shot2Agent Local 1.0.1 — 托盘状态与易用性优化

发布说明草稿；正式发布状态与构建身份以 GitHub Release 为准。

## 这个版本有什么变化

- 托盘用不同轮廓的图标和中文提示显示监听、暂停、待确认、排队、处理、未开启和异常。暂停或关闭截图监听时，已经提交的任务继续处理，提示中同时显示两种状态。
- 有图片等待确认时，可以从托盘回到预览；截图本身不会主动弹出窗口。暂停/恢复菜单互斥，不适用的动作不可用；处理服务失联时显示故障和恢复提示。
- 历史中的“重试结果投递”仅在存在可重试的失败通道时出现，只重新复制、保存或通知，不重新请求 AI。
- 添加 AI 助手时，按兼容安装情况预选或让你明确选择 Codex、Claude Code、GLM，不再默认进入 GLM Token 配置。
- 改善首次使用、预览提交、错误恢复和技术详情文案，保留四页界面与浅色/深色主题。

## 下载与升级

下载正式 Release 的 **Shot2Agent-Windows-x64.zip**，完整解压，双击 **Shot2Agent.exe**。必须保留同级整个 `runtime` 文件夹。普通使用不需要启动 `.cmd`；`Start acceptance.cmd` 仅用于隔离 Fake 测试。

升级前从托盘“退出 Shot2Agent”，备份设置页显示的整个数据目录，再把新版完整解压到另一个目录。程序继续使用原来的 Local 数据；Token 仍由 Windows 凭据管理器保管。不要在应用运行时只复制 SQLite 文件。

首次使用先在窗口中添加 AI 助手，再到设置开启剪贴板监听，选择“确认后提交”和“手动复制”，应用设置后按 Win+Shift+S 截图。保存 Token 不发起模型请求；主动提交图片或测试连接可能按模型服务计费。

## 验证与范围

2026-10-24 操作员反馈“验收已经全部通过”，本轮必要的 Windows 原生托盘验收记录为操作员报告 PASS。已通过且未修改的原生文件复制验收继续保留，没有要求重测。自动化使用隔离目录、合成图片和 Fake/mock，不读取操作员真实 Token、截图、历史，也不发起付费请求。

Windows 原生 API smoke 与操作员实见分别记录；不宣称 CI 代替真实任务栏点击，也不扩大到未单独报告的所有 DPI、Explorer 重启或提供商环境。最终 main 的 CI 链接、源码 SHA、BUILD/MANIFEST 和 ZIP SHA-256 在正式 Release 中列出。

此版本仍是单台 Windows 电脑上的 Local 工具，不进入 Remote/Relay/VPS、Agent 自动故障转移或安装器。不改变稳定的任务 Core、原生文件剪贴板和凭据合同；执行结果不确定的 Agent 任务不会自动重跑。保留 v1.0.0 标签与发布包。
